## 📝 Notes for Maintainers

Before publishing or distributing this repository, replace the placeholders above:

- **`[year]`** → the year of first publication (e.g. `2026`)
- **`[fullname]`** → the name of the copyright holder (individual or organisation)

For projects with multiple copyright holders (typical for community-maintained
medical repositories), use a multi-line copyright block:


statement accurate, consider adding a `AUTHORS` file listing all contributors.

a lightweight alternative some projects use.
